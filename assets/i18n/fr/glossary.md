# Glossaire français

Les choix de la traduction française, pour qu'ils restent les mêmes partout. Voir aussi
`../README.md` (ce qui reste en anglais).

## Grades (US Air Force, par leurs équivalents français)

| Grade | Français | Abréviation |
|---|---|---|
| Second Lieutenant | Sous-lieutenant | S/Lt |
| First Lieutenant | Lieutenant | Lt |
| Captain | Capitaine | Cne |
| Major | Commandant | Cdt |
| Lieutenant Colonel | Lieutenant-colonel | Lcl |
| Colonel | Colonel | Col |

Les décorations américaines (Air Medal, Silver Star...) gardent leur nom propre.

## Typographie

- Espace avant « : », « ; », « ! », « ? » et « % ».
- Majuscules accentuées dans les menus (« ÉCHEC ») ; le HUD les affiche sans accents.
- Les noms des types de cibles (`obj-` de briefings.ftl) portent leur article : « le pont »,
  « la centrale nucléaire ».
