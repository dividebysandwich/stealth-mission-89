# 日本語用語集

日本語訳の用語を統一するための表です。`../README.md`（英語のままにするもの）も参照してください。

## 英語のまま

略語と、日本のパイロットが英語で言う語：

| 英語 | 日本語での扱い |
|---|---|
| HUD, MFD, FLIR, ILS, RWR, ECM, IFF, CCIP, CCRP, SAM, SEAD, CAP, CAS, CSAR, AWACS, SOI, TGP | そのまま |
| Master caution | タイトルは Master caution のまま（操作名ではマスターコーション） |
| snowplow, cursor zero | そのまま（ポッドの機能） |
| Sensor of interest | ツールチップではそのまま |
| 機体名、兵装名、地名 | そのまま |
| ft, kt, nm, lbs, km | そのまま |

## 表記

- 語の間に空白は入れず、全角の句読点（、。）とコロン（：）、括弧（（））を使います。数値や英字の前後には半角空白を入れます。
- 文は丁寧体（です・ます）、ボタンや見出しは体言止め。
- 大文字・小文字の区別がないため、英語で大文字のボタンも通常の表記にします。
- 変数（地名、機体名、パイロット名）には活用や助詞の変化を付けず、コロンや中立の助詞で囲みます。
- 飛行中メニュー、HUD、キーガイド、ニーボードは、ゲームのフォントがCJKを描画できないため英語で表示されます。
