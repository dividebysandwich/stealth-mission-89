# 한국어 용어집

한국어 번역에서 선택한 용어를 어디서나 동일하게 유지하기 위한 문서입니다. `../README.md`
(영어로 유지하는 것)도 참고하세요.

## 영어로 유지

약어와, 한국어권 파일럿이 영어로 말하는 단어:

| 영어 | 한국어에서의 사용 |
|---|---|
| HUD, MFD, FLIR, ILS, RWR, ECM, IFF, CCIP, CCRP, SAM, SEAD, CAP, CAS, CSAR, AWACS, SOI, TGP | 그대로 |
| master caution | Master caution (조종석 라벨) |
| snowplow, cursor zero | 그대로 (타기팅 포드의 기능) |
| 항공기, 무기, 부대, 지명 | 영어 원문 (지명 중 전역 이름은 한국어 표기) |
| ft, kt, nm, lbs, km | 그대로 |

## 표기와 어체

- 단어 사이는 띄어쓰고, 문장 부호는 ASCII를 씁니다 (콜론 뒤에 공백 한 칸).
- 문장은 해요체/합쇼체의 정중하고 간결한 문체, 버튼은 명사형으로 씁니다.
- 변수(지명, 부대, 파일럿)에는 조사를 활용하지 않고 콜론이나 중립적인 조사를 씁니다.
- 한국어에는 대소문자가 없으므로 영어의 대문자 메시지도 그대로 일반 표기로 씁니다.
- 게임의 글꼴은 HUD, 비행 중 메뉴, KEY GUIDE, 니보드에서 한글을 표시하지 못하므로 이 부분은 게임이 영어로 표시합니다.
