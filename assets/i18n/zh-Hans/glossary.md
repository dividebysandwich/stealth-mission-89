# 简体中文词汇表

简体中文译文（中国大陆）的用词选择，以便各处保持一致。另见 `../README.md`（保持英文的内容）。

## 保持英文

缩略语，以及中文飞行员和玩家在模拟器中习惯直接说英文的词：

| 英文 | 中文用法 |
|---|---|
| HUD、MFD、FLIR、ILS、RWR、ECM、IFF、CCIP、CCRP、SAM、SEAD、CAP、CAS、CSAR、AWACS、SOI、TGP | 原样保留 |
| waypoint、steerpoint | 航路点（steerpoint 保留英文） |
| master caution | Master caution |
| chaff | Chaff（说明中可写“箔条”） |
| sensor of interest | Sensor of interest（按键指南和提示中） |
| snowplow、cursor zero | 原样保留（吊舱功能） |
| 飞机、武器、单位和地名 | 原样保留 |
| 单位 ft、kt、nm、lbs、km | 原样保留 |

## 排版

- 词语之间不加空格；中文与英文字母、数字之间加一个空格（如“能见度 40 km”）。
- 使用全角标点：，。：；（）；引号用“”。
- 英文中的大写文字（按钮、HUD、飞行菜单）不分大小写，直接按常规书写。
- 风格中性；避免使用“您”，尽量采用无人称表达（个别提示中偶尔使用）。
- 不对变量（地名、单位名、飞行员名）做变形，使用冒号或中性助词。
- 游戏的 HUD、飞行菜单、按键指南和膝板字体不显示中文，游戏会改显示英文。
