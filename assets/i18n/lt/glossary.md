# Lietuvių kalbos žodynėlis

Lietuviško vertimo sprendimai, kad visur išliktų vienodi. Žr. ir `../README.md` (kas lieka angliška).

Santrumpos ir žodžiai, kuriuos lietuvių lakūnai ir simuliatorių žaidėjai sako angliškai:

| Anglų | Vartosena lietuviškai |
|---|---|
| HUD, MFD, FLIR, ILS, RWR, ECM, IFF, CCIP, CCRP, SAM, SEAD, CAP, CAS, CSAR, AWACS, SOI, TGP | tokie patys |
| waypoint, steerpoint | waypoint |
| trim | trim (autom. trim) |
| master caution | master caution |
| chaff | chaff |

| kneeboard | kneeboard |

## Tipografija

- Daugiskaitos kategorijos (CLDR): one / few / many / other.
- Tūkstančiai skiriami tarpu (2 000), trupmenos kableliu (1,5).
- Dvitaškis rašomas be tarpo prieš jį; vengiama variablių linksniavimo, naudojamos konstrukcijos su dvitaškiu.
